# Bad Wither No Cookie 9minecraft Mod - Silence Annoying Global Sounds

Bad Wither No Cookie 9minecraft Mod lets you silence loud, annoying sounds that play across the entire world. It removes the global broadcast noises from boss spawns and weather, so you only hear them if you stand close to the source. This mod gives you a quiet, peaceful game even on busy multiplayer servers. Features: Boss Sound Fix: Stops the Wither spawn and Ender Dragon death sounds from playing across the whole server. Weather Control: Makes lightning thunder sounds local instead of global.
